# Next: перенос распознавания и перепечатки Keyboop

## Problem Statement
Пользователь хочет отдельный форк нашего приложения: более богатое определение неверной раскладки и механизм замены Keyboop, который не отказывает только потому, что редактор не даёт AX-поле. Основная версия 1.4.12 принята в нескольких приложениях, но строгая обязательная AX-привязка ограничивает совместимость.

## Solution
Отдельный публичный репозиторий alimp01/mac-layout-switcher-next с историей исходного проекта и приложением Mac Layout Switcher Next 1.5.0. Взять из закреплённого Keyboop языковые данные и правила, перенести принцип Backspace + Unicode и порядок событий в наш движок. Сохранить локальную GigaAM-диктовку, настраиваемый Option, выделение, сниппеты, исключения, undo, меню и автозапуск.

## User Stories
1. Как пользователь, я устанавливаю Next отдельно от стабильной версии и различаю их в меню и настройках разрешений.
2. Next проверяет и скачивает обновления только собственного репозитория; стабильное приложение не получает экспериментальный код.
3. Настройки и обученные исключения Next независимы; исходные файлы не перезаписываются. Модель GigaAM остаётся локальной; при миграции допускается только проверенная копия в отдельный каталог, не изменение модели стабильной app.
4. Одновременный перехват двух экземпляров/стабильной и Next предотвращается понятным сообщением; чужой процесс не завершается без пользовательского действия.
5. После пробела/Enter/Tab ошибочная раскладка определяется расширенными словарями RU/EN и триграммами.
6. Правильные слова, технические обозначения, исключения и неоднозначные короткие слова обрабатываются правилами Keyboop; регистр и пунктуация проверяются явно.
7. Исправление возможно во время набора при высокой уверенности, с ограничениями Keyboop для Chromium/Electron и небезопасного контекста.
8. Набранное с начала текущего контекста слово исправляется автоматически и по Option без требования читать AXValue/AXSelectedTextRange.
9. Перепечатка не смешивается с быстрым физическим вводом; Enter/Tab не опережают замену, Shift+Enter сохраняет модификаторы.
10. Навигация, клик, смена приложения, SecureInput, пауза, потеря tap и запись хоткея обнуляют неподтверждённый буфер и отменяют ещё не начатую перепечатку.
11. Выделение и произвольный ранее введённый текст по-прежнему могут использовать проверяемый AX-путь; отсутствие AX для собственного свежего буфера не вызывает старое окно ошибки.
12. Диктовка остаётся через GigaAM v3 с существующими ограничениями вставки, отменой и панелью восстановления.
13. Приложение честно различает отправку синтетики и подтверждённое чтением изменение; при неопределённом результате повторная разрушающая попытка запрещена.
14. В исходниках и бандле доступны лицензии и точная версия заимствований.

## Implementation Decisions
- База 7043925e2f4f7028c6cb1539669290dbf5e0d446; Keyboop fb9bdde4eb8f13a486974cf102a8bec9d607e5d2. Переносить только относящиеся к задаче зависимости, не всё стороннее приложение.
- Идентичность: bundle ID space.alimp.maclayoutswitcher.next, app MacLayoutSwitcherNext.app, display name Mac Layout Switcher Next, независимый Application Support и журнал обновления. Имя Swift executable можно сохранить внутри отдельного бандла.
- Языковые JSON поставляются в бандле и загружаются до обработки клавиатуры. Чистое ядро сохраняет API Detector.verdict, исключения и контекст; добавляется не изменяющее контекст liveVerdict(for:). Источник решений — port Keyboop, а не несколько вручную добавленных слов.
- Правила upstream адаптируются к нашим интерфейсам явно. Любые осознанные расхождения должны быть перечислены и проверены. Сохранить MIT Keyboop contributors и Ilya Granin для языковых данных.
- В Next новая ADR разрешает Backspace/Unicode для достоверного собственного потока клавиш без обязательного AX. Это сознательно переопределяет ADR0013 только для этого пути форка. Существующие AX/dictation пути сохраняют свои проверки.
- Перенести упорядоченный burst событий из Keyboop и/или последовательную очередь с перехватом физического ввода для поддерживаемых сценариев. Нельзя просто вернуть удаление в старый Typist, оставив обязательный InputFocusGuard перед ним.
- Разрешён перенос TIS/UCKeyTranslate data в предварительно прогретый immutable cache с обновлением по уведомлениям источника ввода; lifetime uchr data сохраняется. Контекст приложения и SecureInput кешируются вне callback.
- Spotlight/nonactivating panels должны получать глобальную синтетику как у Keyboop, а не только postToPid фонового NSWorkspace frontmost.
- Нет AX/TIS/файлового I/O/sleep в EventTap callback; языковые данные и системные классификации подготавливаются заранее. Если inline-прогон невозможен, не создавать скрытую гонку с удалением.
- Короткий достоверный буфер, поколение контекста, secure-input и проверка физических модификаторов обязательны. Без AX нельзя обещать подтверждение точного поля или результата. Никаких автоматических повторов после начала удаления.
- Unicode порции ограничены и не разрывают surrogate pair. Поведение постинга/раскладки/собственных маркеров проверяется на нативном стенде; не выдавать post за readback.
- Выделение/диктовка не начинают автоматически использовать clipboard. Пользователь запросил основной механизм перепечатки; расширение clipboard-доступа не требуется.
- Auto-путь Next включён по умолчанию; live-исправление — только с ограничениями исходного Keyboop, без Chromium/Electron mid-word. Не включать два глобальных переключателя одновременно.

## Testing Decisions
- Сначала зафиксировать literal/parity примеры и baseline поведение, затем проверять новый детектор и настоящий Engine путь.
- Общий набор: ghbdtn/привет, срфе/chat, b/B/z/Z, cgfcb,j, слова с обёртками, ozon/claude/gameboy, правильные RU/EN, цифры/URL/сокращения/коллизии, исключение и undo, смешанный ввод. Старые тесты, расходящиеся с upstream, не удалять молча: документировать новый контракт.
- Паритет с закреплённым upstream на независимом наборе входов; тестировать решения, не только наличие JSON. Измерение на curated наборе не называть реальной точностью.
- Нативный стенд: AX отсутствует, но собственный свежий ghbdtn исправляется по Space и Option; Enter/ShiftEnter/Tab порядок; быстрый ввод; смена поля/приложения и клики; SecureInput; модификаторы; abort до мутации и failure после начала; отсутствие автоматического повтора; emoji/UTF16; восстановление tap.
- Существующие speech/model/selection и updater тесты по релевантности. Полный Linux swift test, native build включая speech, signed app/DMG mounted verification.
- Два независимых ревью Spec/Standards. Аппаратная приёмка остаётся отдельным статусом: не вводить в личные редакторы и не обходить ограничения UI/TCC.

## Out of Scope
Перенос Whisper/Parakeet, переводчика, истории clipboard и остальных функций Keyboop; изменение стабильного main/архива/app; обещание всех окон, удалённых рабочих столов или App Store; принудительная выдача macOS разрешений.
